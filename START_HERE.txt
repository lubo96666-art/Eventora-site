Eventora - quick start

IMPORTANT - OPEN AS A MAVEN PROJECT

1. Extract the archive into a NEW empty folder. Do not copy it over an older Eventora folder.
2. In IntelliJ IDEA choose File -> Open.
3. Select Eventora/pom.xml (the pom.xml file itself), then choose "Open as Project".
4. Wait until the Maven dependency download and indexing are complete.
5. The Project SDK and language level must be Java 17.

If IntelliJ shows "package jakarta.servlet.http does not exist":

1. Close the project.
2. Delete only the .idea folder created by IntelliJ and any *.iml file in your extracted copy.
3. Open pom.xml again as described above.
4. Open the Maven panel and click "Reload All Maven Projects".
5. You can also run CHECK-MAVEN-WINDOWS.bat to download and verify all dependencies.

LOCAL DEMO (NO DOCKER REQUIRED)

1. Open pom.xml as a Maven project in IntelliJ IDEA.
2. Wait for Maven to download the dependencies.
3. Run EventoraApplication.java normally with the green arrow next to main().
4. Do not select or enter any active profile.
5. Wait for: Started EventoraApplication
6. Open: http://localhost:8080/visualization

EXAM MODE (MYSQL - ASSIGNMENT PROFILE)

1. Start Docker Desktop.
2. Run: docker compose up -d
3. Set active profile to: mysql
4. Wait for: Started EventoraApplication
5. Open: http://localhost:8080/visualization

H2 is configured directly in application.properties for reliable local use.
The separate mysql profile contains the assignment-compliant MySQL setup.
